I encountered the following error when I was trying to start my Oracle Database:

ORA-00821: Specified value of sga_target ****M is too small, needs to be at least ****M
---

## Environment Details:

- **DB Version:** Oracle Database 11g Release 11.2.0.4.0 - 64bit Production
- **DB Server Operating System:** RHEL 7.9

---

## Steps Taken to Resolve the Issue:

Initially, I restarted the database server, but unfortunately, the issue persisted.

### Identifying Parameters in `spfile****.ora`:
I identified the following two parameters in the file located at:

`$ORACLE_HOME/dbs/spfile****.ora`

`*.sga_max_size=4033164800`

`*.sga_target=4033164800`

Since the `spfile****.ora` file is a binary file and cannot be edited directly, I needed to convert it to a text-readable format.

### Converting SPFILE to PFILE:
To achieve this, I logged in as `sysdba` and executed the following command to create a parameter file (PFILE):

`CREATE PFILE='/tmp/temp_params.ora' FROM SPFILE;`

This created an editable file, which I then modified as follows:

`*.sga_max_size=5033164800`

`*.sga_target=5033164800`

### Recreating SPFILE with Updated Parameters:
After saving the changes, I logged in again as `sysdba` and executed the following command to recreate the `spfile` with the updated parameters:

`CREATE SPFILE='/<put your oracle home path>/dbs/spfile****.ora' FROM PFILE='/tmp/temp_params.ora';`

Finally, I was able to start the database without encountering the error.
